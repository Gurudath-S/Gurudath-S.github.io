# Audio Files

This directory contains audio files for the portfolio website.

## Background Music
- Place your background music file here as `background-music.mp3`
- Recommended format: MP3 (best browser compatibility)
- Recommended length: 2-5 minutes (will loop automatically)
- Recommended volume: Keep the original audio at moderate volume, the app will control playback volume

## Click Sounds
- You can add click sound files here for future use
- Example: `click-sound.mp3`

## Audio Guidelines
- File size: Keep under 5MB for good loading performance
- Format: MP3 is recommended for best compatibility
- Quality: 128kbps is sufficient for background music
- Loop-friendly: Ensure the audio loops seamlessly if intended

## Free Audio Resources
- Freesound.org
- Zapsplat.com (requires free account)
- YouTube Audio Library
- Pixabay Audio
- Incompetech.com (Kevin MacLeod music)

## Usage
The audio will only play on desktop devices (screen width >= 768px).
Mobile devices will have audio disabled for better user experience.
